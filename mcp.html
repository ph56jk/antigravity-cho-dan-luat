Kết nối thư viện prompt vào AI của bạn

MCP là cách cắm thêm “công cụ” cho trợ lý AI. Sau khi cài, AI trong Antigravity (hoặc Claude, Cursor…) tự tra thư viện hơn 1.700 prompt: bạn chỉ cần nói “soát giúp mình hợp đồng thuê nhà, mình là bên thuê”, AI tự tìm prompt hợp nhất, hỏi bạn chỗ còn thiếu rồi làm theo.

⚡ Nhờ AI tự cài (dễ nhất) 🛠️ Tự cài bằng tay 🧩 Claude, Cursor… 💬 Cách dùng 🩺 Lỗi thường gặp
An toàn: chương trình chạy ngay trên máy bạn và chỉ làm một việc: đọc danh sách prompt (tải từ trang này, có lưu sẵn để dùng khi mất mạng). Nó không đọc file của bạn và không gửi gì đi đâu. Mã nguồn ngắn, mở xem được tại mcp/server.js.

1 Cách dễ nhất: nhờ Antigravity tự cài

Mở Antigravity, chọn một thư mục bất kỳ, dán prompt dưới đây vào khung chat rồi gửi. Agent sẽ kiểm tra máy, tải file, sửa cấu hình và báo bạn khi xong. Khi nó xin phép chạy lệnh, đọc qua rồi bấm đồng ý.

Prompt tự cài MCP “Thư viện prompt cho dân luật”
Cài giúp mình MCP server "Thư viện prompt cho dân luật" vào Antigravity. Làm lần lượt, mỗi bước báo kết quả ngắn gọn:

1. Kiểm tra Node.js bằng lệnh: node -v
   Nếu chưa có hoặc phiên bản dưới 18 thì DỪNG LẠI, hướng dẫn mình cài bản LTS ở https://nodejs.org rồi bảo mình gửi lại prompt này. Không tự cài Node.

2. Tạo thư mục .prompt-luat trong thư mục người dùng (home) của máy này, rồi tải file
   https://ph56jk.github.io/antigravity-cho-dan-luat/mcp/server.js
   về thư mục đó, đặt tên server.js. Cho mình biết đường dẫn tuyệt đối của file.

3. Chạy thử: gửi dòng {"jsonrpc":"2.0","id":1,"method":"tools/list"} vào stdin của lệnh "node <đường dẫn tuyệt đối>/server.js". Kết quả phải có 3 tool: search_prompts, get_prompt, list_categories.

4. Tìm file cấu hình MCP của Antigravity: ~/.gemini/config/mcp_config.json hoặc ~/.gemini/antigravity/mcp_config.json (trên Windows là C:\Users\<tên>\.gemini\...). Dùng file nào đang tồn tại; nếu có cả hai thì sửa cả hai; nếu chưa có thì tạo ~/.gemini/config/mcp_config.json.
   Sao lưu file thành mcp_config.json.bak trước khi sửa. Thêm vào trong "mcpServers" (giữ nguyên các server khác, giữ JSON hợp lệ):
   "prompt-luat": { "command": "node", "args": ["<đường dẫn tuyệt đối tới server.js>"] }
   Trên Windows nhớ viết dấu \ thành \\ trong JSON.

5. Cho mình xem đoạn cấu hình đã thêm, rồi nhắc mình: bấm "..." ở khung agent → MCP Servers → Manage MCP Servers → Refresh (hoặc khởi động lại Antigravity) để thấy server prompt-luat.

Không sửa hay xoá file nào khác ngoài các file nêu trên.

Xong rồi, thử hỏi: “Dùng thư viện prompt luật, tìm giúp mình prompt soạn đơn ly hôn thuận tình.”

2 Tự cài bằng tay (3 bước)

  1. Cài Node.js bản LTS từ nodejs.org (nếu chưa có). Mở Terminal (macOS) hoặc PowerShell (Windows), gõ node -v, thấy v18 trở lên là được.
  2. Tải chương trình về thư mục .prompt-luat trong thư mục người dùng:
macOS / Linux (Terminal)
mkdir -p ~/.prompt-luat && curl -fsSL https://ph56jk.github.io/antigravity-cho-dan-luat/mcp/server.js -o ~/.prompt-luat/server.js && echo "$HOME/.prompt-luat/server.js"
Windows (PowerShell)
New-Item -ItemType Directory -Force "$HOME\.prompt-luat" | Out-Null; Invoke-WebRequest https://ph56jk.github.io/antigravity-cho-dan-luat/mcp/server.js -OutFile "$HOME\.prompt-luat\server.js"; "$HOME\.prompt-luat\server.js"

Dòng cuối lệnh in ra đường dẫn đầy đủ của file, ví dụ /Users/lan/.prompt-luat/server.js hoặc C:\Users\lan\.prompt-luat\server.js. Giữ lại để dùng ở bước 3.

  1. Thêm vào Antigravity: ở khung agent bấm … → MCP Servers → Manage MCP Servers → View raw config. File mcp_config.json mở ra; thêm mục prompt-luat vào trong "mcpServers", thay đường dẫn bằng đường dẫn của bạn, lưu lại rồi bấm Refresh.
mcp_config.json (macOS / Linux)
{
  "mcpServers": {
    "prompt-luat": {
      "command": "node",
      "args": ["/Users/TEN-CUA-BAN/.prompt-luat/server.js"]
    }
  }
}
mcp_config.json (Windows)
{
  "mcpServers": {
    "prompt-luat": {
      "command": "node",
      "args": ["C:\\Users\\TEN-CUA-BAN\\.prompt-luat\\server.js"]
    }
  }
}
Đã có server khác trong file? Đừng dán đè cả file. Chỉ thêm khối "prompt-luat": { … } vào trong "mcpServers", ngăn cách với server trước bằng dấu phẩy. Sai một dấu phẩy là Antigravity không đọc được cả file.

3 Dùng với ứng dụng AI khác

Đa số ứng dụng hỗ trợ MCP dùng chung kiểu cấu hình trên ("command": "node" + đường dẫn tới server.js). Làm bước 1–2 ở trên trước, rồi:

Ứng dụngThêm ở đâu
Claude DesktopSettings → Developer → Edit Config, thêm khối prompt-luat giống trên vào "mcpServers" trong claude_desktop_config.json, rồi tắt hẳn và mở lại Claude.
Claude CodeChạy claude mcp add prompt-luat -s user -- node ~/.prompt-luat/server.js
Codex CLIChạy codex mcp add prompt-luat -- node ~/.prompt-luat/server.js
CursorSettings → MCP → Add new MCP server, hoặc thêm khối trên vào ~/.cursor/mcp.json.
Gemini CLIThêm khối trên vào "mcpServers" trong ~/.gemini/settings.json.
Cho người rành kỹ thuật: chạy thẳng từ GitHub bằng npx

Nếu máy có sẵn Git và Node, có thể bỏ qua bước tải file và dùng "command": "npx", "args": ["-y", "github:ph56jk/antigravity-cho-dan-luat"]. Biến môi trường PROMPT_LUAT_OFFLINE=1 tắt việc tự cập nhật; PROMPT_LUAT_URL trỏ sang thư viện prompt khác cùng định dạng.

4 Cài xong thì dùng thế nào?

Cứ nhắn yêu cầu như bình thường. Nếu AI chưa tự dùng thư viện, thêm câu “dùng thư viện prompt luật” vào yêu cầu. Ví dụ:

Ví dụ yêu cầu
Dùng thư viện prompt luật: mình là bên thuê, soát giúp mình @hop-dong-thue-mat-bang.docx.

Tìm trong thư viện prompt luật 3 prompt ôn thi môn Luật Đất đai, cho mình chọn rồi làm luôn.

Thư viện prompt luật có những nhóm nào? Liệt kê các loại hợp đồng có sẵn prompt.

Lấy nguyên văn prompt "Checklist hồ sơ: đăng ký kết hôn" để mình copy.

AI có thêm 3 công cụ

search_prompts — tìm prompt theo từ khoá, có dấu hay không dấu đều được, lọc theo nhóm.
get_prompt — lấy nội dung đầy đủ của một prompt kèm hướng dẫn để AI làm theo đúng cách (hỏi bạn chỗ [GHI …], nhắc đính kèm file).
list_categories — xem các nhóm và chủ đề con (loại hợp đồng, thủ tục, môn học…).

Ứng dụng nào hỗ trợ MCP prompts (gõ / trong ô chat) sẽ thấy thêm 30 prompt chọn lọc và lệnh tim-prompt-luat: bạn chỉ cần mô tả việc cần làm.

5 Lỗi thường gặp

Không thấy server prompt-luat

  • Bấm Refresh trong Manage MCP Servers hoặc khởi động lại ứng dụng.
  • Kiểm tra file cấu hình là JSON hợp lệ (thường do thiếu / thừa dấu phẩy).
  • Đường dẫn phải là đường dẫn đầy đủ, không dùng ~ trong "args".

Báo lỗi “node” hoặc server tắt ngay

  • Chưa cài Node.js, hoặc phiên bản dưới 18: cài lại bản LTS rồi mở lại ứng dụng.
  • Nếu vẫn lỗi, thay "node" bằng đường dẫn đầy đủ (gõ which node trên macOS, where node trên Windows để xem).
  • Lần chạy đầu cần có mạng để tải danh sách prompt; sau đó dùng được khi mất mạng.

Gỡ cài đặt

Xoá khối "prompt-luat" trong file cấu hình MCP, rồi xoá thư mục .prompt-luat trong thư mục người dùng.

Prompt chỉ là khung yêu cầu. Kết quả AI làm ra, nhất là điều luật, số hiệu văn bản, thời hạn, lệ phí, phải được bạn tra lại ở vbpl.vn hoặc nguồn chính thức trước khi dùng.

Trang hướng dẫn không chính thức, không liên kết với Google hay Anthropic. Nội dung chỉ mang tính tham khảo và không phải tư vấn pháp lý.
